# Skills

A collection of Gage's agent skills.

Each skill lives in `skills/<skill-name>/SKILL.md`.

## Skills

- [pico8-download-save](skills/pico8-download-save/SKILL.md): plan a small PICO-8 game, then get PICO-8, download a cartridge, and save it.

## Install

This is a private source repository. People need access to it to install from here.

```bash
npx skills@latest add https://github.com/gageminamoto/skills --skill pico8-download-save
```

To make a skill publicly installable by anyone, publish it from a public GitHub repository or public mirror.
