# Agent Skills

A collection of agent skills by Gage, made at [Negi Studio](https://www.negi.studio), a digital product studio for playful software.

Each skill lives in `skills/<skill-name>/SKILL.md`.

## Skills

- [pico8-start](skills/pico8-start/SKILL.md): plan a small PICO-8 game, then get PICO-8, download a cartridge, and save it.
- [write-prd](skills/write-prd/SKILL.md): draft a concise PRD with Context, Usage scenarios, and issue-ready Issues sections.

## Install

This repository is public. Install a skill with:

```bash
npx skills@latest add https://github.com/gageminamoto/skills --skill pico8-start
npx skills@latest add https://github.com/gageminamoto/skills --skill write-prd
```
